# BAT キャラ配信

OBSで使う1920×1080のPNGTuberです。

操作ドック：https://ura-news.github.io/stream-op-git/avatar/
表示ソース：https://ura-news.github.io/stream-op-git/avatar/overlay.html
動く背景だけ：https://ura-news.github.io/stream-op-git/avatar/background.html

通常時は固定。音量と発話のリズムで口が開閉します。白い仮面の目穴を残し、参考の黒目・口と元絵の短い腕・腰の手を組み合わせています。

手動：ぽりぽり、一服、煙付きのおなら、瞬き、にっこり、通常。操作ドック選択中は1〜5と0でも操作できます。
自動：45〜90秒間隔、オン／オフ可能。一服とこたつモードの選択に対応。おならは手動のみ。

大きさ・位置タブから30〜200%・左右・上下を変更、保存、リセットできます。背景のオン／オフも同じタブです。

別PC：OBSのWebSocketサーバーを有効にし、接続・マイクタブにそのPCのポートとパスワードを入力。その後「このPCのOBSにキャラを追加」を押します。表示URLとドックURLをコピーしOBSに登録できます。各PCのマイクを選択してください。ローカルサーバーとNode.jsは不要です。

音声とパスワードは外部へ送信しません。パスワードを含む設定URLのフラグメントはHTTPリクエストに含まれません。設定URLはそのPC専用なので他人へ共有しないでください。

背景は可愛い男の配信部屋。星・雲・灯りが動きます。喫煙時は火先から煙が漂います。おならは0.78秒の合成効果音。効果音音量0%で消音。
